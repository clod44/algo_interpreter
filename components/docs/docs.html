How Algo works
Program shape
Every program needs exactly one START and one FINISH. Code runs from top to bottom unless a GO jumps.
Output
ECHO value writes without a newline. LINE value writes the value and adds a newline afterward.
Variables
Assign with name = value. Update with +=, -=, *=, or /=.
Conditions
IF cond THEN cmd ELSE cmd chooses one command. Comparisons include ==, >, <.
Loops and jumps
GO line jumps to the first statement on that source line.
